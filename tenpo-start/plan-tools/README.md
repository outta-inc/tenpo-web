# TENPO/START 計画アプリ（plan/index.html）の点検道具

計画アプリは `tenpo-start/plan/index.html` の1つのファイルが正本です（画面・見た目・動き・埋め込んだヒアリング）。
ヒアリングの質問だけは `tenpo-start/interview-src/` が元で、`embed.mjs` で index.html の `/*IV:BEGIN*/`〜`/*IV:END*/` に入れます。そこは直接直さないでください。

2026/11/23 に、版ごとに後ろへ重ねていた上書き（同じ関数の定義し直し・包み直し・後から足していた見た目）を、1つの定義ずつにまとめました。今後は該当する関数を直接直してください。

## 点検のしかた
`tenpo-start/` で `python3 -m http.server 8765` を動かしてから、Playwright（Python）で次を実行します。

- `python3 crawl.py <0〜7>`：サンプル5業態（a・d・t・c・b）と、ヒアリングに答えた3業態（カフェ・持ち帰り・サロン）の8通り。全タブ・9つの中を開き、画面のボタンを押して回り、ページのエラー・「undefined／NaN」などの表示・横のはみ出しを出します。何も出なければ合格。
- `python3 wording.py`：4業態の全画面で、もう使わない言葉（家賃に回せる額・参考額・手元に残したい額）が残っていないかを探します。公庫の制度の「上限」だけが出れば合格。
- `walk2.py`：ヒアリングを最後まで答える手順（crawl.py が使う）。
- `node unused.js ../plan/index.html`：どこからも呼ばれていない関数を一覧にします（`cut` を付けると消す）。
- `node dedup.js ../plan/index.html`：同じ名前で定義し直された関数の、古い方を消します。

## 計算の考え方（2026/11/22〜23）
- 家賃は実際の物件か、見た家賃（`refRent`：選んだ物件 → 見た家賃）。「家賃に回せる額」は使わない。
- 答えは「続けるのに1日に何人要るか」（`hmNeed`）。家賃が無い時だけ「家賃を払う前に残る額」。
- 手元に残す額は「あなたの取り分」＝給料（または店長の給料）＋お店に残す額（`s.ow` → `s.f.keep`）。
- 数字は「計算のもと」（`cbSheet`）で、お店のやり方を選んで決める。
